# Implementation phases

## Verification result

The roadmap matches the assignment's core product model. The build order has
been adjusted so the connected public-to-admin workflow is complete before
stretch features.

## Phase 1: Foundation and data

- Next.js App Router and TypeScript
- Nomichi design tokens and shared UI
- Supabase browser, server, and middleware clients
- Relational schema, indexes, policies, triggers, and seed data

## Phase 2: Public enquiry

- Live open-trip listing
- Mobile-first enquiry form
- Server-side validation and persistence
- Empty, loading, error, and warm success states

## Phase 3: Authentication

- Real Supabase password login
- Protected admin routes
- Admin navigation and logout

## Phase 4: Lead CRM

- Search and filters
- Lead detail and pipeline updates
- Ownership
- Timestamped call notes and next actions
- Activity timeline

## Phase 5: Trips and overview

- Create and edit trips
- Dashboard totals by stage and trip
- Closed trips excluded from the public page

## Phase 6: Useful stretch work

- AI-assisted WhatsApp draft
- CSV export
- Responsive polish, accessibility, README, and deployment instructions

## External handoff

Creating the production Supabase project, Vercel project, public GitHub URL, and
evaluator login requires account access. The repository will include everything
needed for that final handoff without committing secrets.
